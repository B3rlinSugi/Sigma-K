# ADR-014: Containerization & Deployment Strategy

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Kak Nabila (Mentor)

## Context
Lokasi server hosting target (Pusat Data Nasional vs On-Premise VM KemenPANRB) masih berstatus [TBD]. Arsitektur deployment wajib mandiri dan mudah dipindahkan (*portable*).

## Decision
Menetapkan **Multi-Stage Docker Containerization + Docker Compose + Nginx Reverse Proxy + GitHub Actions CI/CD Pipeline**.

## Alternatives Considered
- *Direct Bare-Metal PM2 Setup:* Kurang portabel dan rentan terhadap perbedaan konfigurasi environment antar-server.
- *Full Kubernetes Cluster:* Memerlukan beban pengelolaan infrastruktur yang terlalu berat untuk skala deployment saat ini.

## Consequences
- **Positive:** Aplikasi dapat dijalankan dengan 1 perintah di server mana pun, isolasi dependensi terjamin, CI/CD terotomatisasi penuh.
- **Negative:** Diperlukan pemahaman Docker pada tim deployment kementerian.
