# ADR-002: Frontend Technology Stack Selection

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Kak Nabila (Mentor)

## Context
Antarmuka SIGMA-K harus menyajikan kesan visual berkelas (*Executive Grade*) untuk presentasi SESDEP, mampu me-render kanvas pohon struktur organisasi yang responsif, komparasi delta verifikasi, serta realtime alert.

## Decision
Memilih **Next.js 14+ (App Router) + React 18 + TypeScript + Tailwind CSS + React Flow + TanStack Query + Zustand**.

## Alternatives Considered
- *Vite + React SPA:* Baik, namun Next.js App Router memberikan SSR yang memangkas waktu pemuatan awal dashboard eksekutif.
- *Nuxt / Vue.js:* Ekosistem visualisasi pohon dan charting React lebih matang di industri.

## Consequences
- **Positive:** Dukungan server-side rendering untuk halaman awal, ekosistem React Flow yang kaya untuk kanvas bagan organisasi, full type-safety dengan TypeScript.
- **Negative:** Pembelajaran App Router conventions, namun sudah dikuasai oleh Lead Engineer.
