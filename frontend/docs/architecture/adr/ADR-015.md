# ADR-015: Repository Strategy (Monorepo Workspace)

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Ikhsan (Data Analyst), Kak Nabila (Mentor)

## Context
Project dikembangkan oleh 1 Full-Stack Engineer dan 1 Data Analyst dengan kebutuhan kontrak antarmuka tipe data TypeScript yang sinkron antara frontend dan backend, serta repositori terpadu untuk dokumentasi dan deployment.

## Decision
Memilih struktur **Monorepo Workspace (Turborepo / npm workspaces)**.

## Alternatives Considered
- *Multi-Repo (Repo Frontend, Repo Backend, Repo Data terpisah):* Memperumit sinkronisasi tipe data DTO, memerlukan banyak pull request terpisah, dan menyulitkan pelacakan dokumentasi project.

## Consequences
- **Positive:** Berbagi tipe data DTO `@sigma/types` secara atomik, satu perintah setup lokal untuk seluruh stack, dokumentasi tersentralisasi di `docs/`.
- **Negative:** Repositori menjadi lebih besar secara ukuran, namun sangat terkelola dengan Turborepo.
