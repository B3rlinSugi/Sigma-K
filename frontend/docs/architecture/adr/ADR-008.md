# ADR-008: Organization Hierarchy Data Modeling

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Ikhsan (Data Analyst)

## Context
Struktur organisasi kementerian bersifat hierarkis (parent-child) dan sering mengalami pemindahan unit (*re-parenting*) saat restrukturisasi birokrasi.

## Decision
Memilih model **Adjacency List (`parent_id`) yang dipadukan dengan PostgreSQL Recursive CTE dan Algoritma DFS Cycle Detection Guard**.

## Alternatives Considered
- *Nested Set Model:* Ditolak karena pemindahan 1 unit kerja akan memaksa penulisan ulang indeks `lft/rgt` di seluruh baris tabel ($O(N)$ write lock).
- *Materialized Path:* Parsing string rentan terhadap inkonsistensi saat rename kode unit.

## Consequences
- **Positive:** Operasi pemindahan unit kerja berjalan instan ($O(1)$), pohon diambil sangat cepat via Recursive CTE, integritas data terlindungi Foreign Key.
- **Negative:** Diperlukan query rekursif saat mengekstraksi seluruh pohon hierarki.
