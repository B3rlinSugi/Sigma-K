# ADR-011: Document Storage Strategy

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Kak Nabila (Mentor)

## Context
Operator instansi mengunggah dokumen digital dasar hukum regulasi (PDF Perpres/Permen) maksimal 10 MB. Sistem harus menyimpan berkas secara aman dan tidak boleh terkunci pada cloud provider tertentu.

## Decision
Menerapkan **Pluggable Storage Driver Pattern** dengan driver **Local Disk Storage** (untuk Development lokal) dan **MinIO / S3-Compatible Storage** (untuk Staging & Produksi PDN) yang dilindungi *Time-Limited Pre-Signed URLs*.

## Alternatives Considered
- *Menyimpan File sebagai BLOB di Database:* Membuat ukuran database membengkak dan menurunkan performa query.
- *Public Web Accessible Folder:* Berisiko terhadap kebocoran dokumen regulasi internal yang belum diundangkan.

## Consequences
- **Positive:** Berkas aman dalam private bucket, akses terkontrol via token bertanda tangan, zero cloud lock-in.
- **Negative:** Diperlukan kontainer MinIO pada deployment staging.
