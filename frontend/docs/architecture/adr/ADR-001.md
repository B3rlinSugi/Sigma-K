# ADR-001: Architecture Style Selection

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Ikhsan (Data Analyst), Kak Nabila (Mentor)

## Context
SIGMA-K adalah sistem pengelolaan master data kelembagaan nasional, kabinet kepresidenan, dan struktur organisasi berjenjang dengan kebutuhan transaksi approval atomik dan notifikasi realtime. Tim implementasi beranggotakan 1 Full-Stack Engineer dan 1 Data Analyst dalam batas waktu magang.

## Decision
Memilih **Modular Monolith with Event-Driven Realtime Components**.

## Alternatives Considered
- *Traditional Monolith:* Ditolak karena batasan antar-modul tidak terisolasi dan rawan *spaghetti code*.
- *Microservices:* Ditolak karena beban operasional jaringan (Kubernetes, distributed tracing, Saga transactions) terlalu tinggi untuk tim magang.

## Consequences
- **Positive:** Transaksi persetujuan data draf ke master data berjalan atomik (ACID) dalam satu database, kemudahan refactoring, dan pengiriman event realtime via internal event bus / Redis.
- **Negative:** Seluruh modul berbagi satu proses runtime, namun batas modul yang bersih memungkinkan ekstraksi service mandiri di masa depan jika diperlukan.
