# ADR-013: Analytics Workload & Read Model Strategy

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Ikhsan (Data Analyst), Pak Sigit (Mentor Lead Data Analyst)

## Context
Dashboard eksekutif SESDEP dan modul analitik Data Analyst membutuhkan agregasi data postur kelembagaan tanpa mengunci (*locking*) tabel transaksi master.

## Decision
Menerapkan **Materialized Views Terindeks + Redis Analytical Cache + Akun Database Read-Only Khusus Data Analyst**.

## Alternatives Considered
- *Full Data Warehouse (Snowflake / BigQuery):* Ditolak karena over-engineering untuk skala data saat ini.
- *Query Agregat Langsung ke Live Table:* Berisiko memperlambat transaksi penulisan master data saat pimpinan membuka dashboard.

## Consequences
- **Positive:** Pemuatan dashboard eksekutif berkecepatan tinggi ($< 50$ ms), Data Analyst dapat menjalankan kueri analitik secara aman tanpa mengganggu transaksi produksi.
- **Negative:** Diperlukan mekanisme refresh berkala pada Materialized Views.
