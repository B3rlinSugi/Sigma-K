# ADR-007: Realtime Notification Transport Selection

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Kak Nabila (Mentor)

## Context
REQ-011 mewajibkan pengiriman notifikasi mutasi data secara realtime ke peramban pengguna aktif dengan latensi $< 1$ detik.

## Decision
Memilih **Socket.io / WebSocket Gateway over TLS 1.3** dengan Redis Adapter dan fallback long-polling.

## Alternatives Considered
- *HTTP Short Polling:* Membebani server dengan jutaan request kosong dan boros bandwidth.
- *Server-Sent Events (SSE):* Bagus untuk satu arah, namun Socket.io menyediakan penanganan room, handshake token, dan acknowledgement pesan yang lebih komprehensif.

## Consequences
- **Positive:** Komunikasi persisten dua arah berkecepatan tinggi, broadcast per room instansi dan user instan.
- **Negative:** Diperlukan port proxying WSS di konfigurasi Nginx.
