# ADR-005: Authentication Strategy & Pluggable SSO

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Kak Nabila (Mentor)

## Context
Kebutuhan Single Sign-On (SSO) KemenPANRB / ASN Digital masih berstatus [TBD]. Sistem membutuhkan otentikasi mandiri yang aman saat ini, namun tidak boleh melakukan rewrite besar jika SSO diwajibkan di kemudian hari.

## Decision
Menerapkan **Pluggable Dual-Token Strategy (Bcrypt Hashing + Stateless JWT Access Token + Stateful Redis Refresh Token in HttpOnly Cookies)** dengan modul **OpenID Connect (OIDC) Strategy Adapter** yang siap diaktifkan.

## Alternatives Considered
- *Session Cookie Murni:* Sulit diskalakan untuk WebSocket handshake dan API mobile masa depan.
- *Mandatory SSO Langsung:* Berisiko memblokir rilis jika akses server IdP KemenPANRB belum diberikan.

## Consequences
- **Positive:** Otentikasi lokal berjalan aman 100%, sesi dapat di-revoke instan via Redis, integrasi SSO siap dipasang kapan saja via konfigurasi.
- **Negative:** Diperlukan Redis instance untuk pengelolaan state refresh token.

## Open Questions
- Kepastian protokol resmi IdP KemenPANRB (SAML vs OIDC).
