# ADR-003: Backend Framework Selection

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Kak Nabila (Mentor)

## Context
Backend SIGMA-K harus menerapkan arsitektur modular, routing terstruktur, dependency injection, penanganan WebSocket realtime native, dan type-sharing yang mulus dengan frontend Next.js.

## Decision
Menetapkan **NestJS 10+ (TypeScript Strict) dengan Prisma ORM** sebagai rekomendasi backend utama *(Alternatif Resmi: Laravel 11 PHP)*.

## Alternatives Considered
- *Laravel 11 (PHP):* Sangat kuat untuk CRUD, namun penanganan WebSocket realtime dan integrasi tipe TypeScript dengan Next.js membutuhkan tooling terpisah.
- *Spring Boot (Java):* Terlalu berat dan memperlambat iterasi tim magang.

## Consequences
- **Positive:** Full-stack TypeScript terpadu, modul terisolasi ketat, integrasi native Socket.io gateway dan Event Emitter.
- **Negative:** Diperlukan konfigurasi Prisma transaction yang disiplin untuk mutasi kompleks.
