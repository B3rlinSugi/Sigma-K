# ADR-010: API Architecture, Versioning & Uniform Contracts

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Kak Nabila (Mentor)

## Context
SIGMA-K membutuhkan antarmuka komunikasi data yang terstandarisasi, mudah diuji, terdokumentasi otomatis, dan siap dikonsumsi oleh web client maupun potensi mobile app di masa depan.

## Decision
Menetapkan arsitektur **RESTful API v1 (`/api/v1/`)** dengan standar **Uniform Response Wrapper**, **Strict DTO Validation**, dan dokumentasi interaktif **OpenAPI / Swagger**.

## Alternatives Considered
- *GraphQL:* Terlalu kompleks untuk kebutuhan CRUD dan workflow SIGMA-K saat ini, serta menyulitkan caching HTTP gateway standar.
- *gRPC:* Baik untuk komunikasi antar-microservices, namun frontend browser membutuhkan wrapper gRPC-web tambahan.

## Consequences
- **Positive:** Standar industri luas, kemudahan debugging, integrasi langsung dengan TanStack Query di frontend.
- **Negative:** Diperlukan DTO terpisah untuk setiap endpoint request/response.
