# ADR-004: Primary Database Engine Selection

- **Status:** APPROVED
- **Date:** 2026-08-25
- **Deciders:** Berlin (Lead Software Architect), Ikhsan (Data Analyst), Pak Sigit (Mentor Lead Data Analyst)

## Context
SIGMA-K membutuhkan database relasional dengan kemampuan query pohon rekursif (Recursive CTE) untuk bagan organisasi, indexing JSONB untuk audit trail, dan integritas ACID mutlak.

## Decision
Memilih **PostgreSQL 16+**.

## Alternatives Considered
- *MySQL 8.0 (Legacy DB):* Dukungan JSON indexing dan recursive CTE kurang optimal dibandingkan PostgreSQL.
- *MongoDB:* Tidak memiliki integritas foreign key relasional yang ketat untuk kabinet dan organisasi.

## Consequences
- **Positive:** Performa kueri rekursif hierarkis pohon unit kerja yang sangat cepat, dukungan JSONB GIN index untuk snapshot audit log, dan kesiapan PostGIS di masa depan.
- **Negative:** Diperlukan script ETL untuk migrasi data awal dari MySQL legacy `eskld` ke PostgreSQL baru.
